# Public Apparent site on Clanker

`https://app.tryapparent.com/` currently reaches Clanker's `presentations-caddy-1` through Cloudflare. The live Caddyfile is `/opt/presentations/Caddyfile`; the site root is the `apparent-site` symlink under `/opt/presentations/releases/`, mounted in Caddy as `/srv/apparent-site`. This is separate from the Worker described in `site/wrangler.jsonc`. Check the live origin before assuming either route owns the hostname.

Build from the intended commit with `npm run build`, then `node scripts/package-apparent.mjs` in `site/`. Run the focused Node tests in `site/scripts/`. Publish **only** `site/dist-apparent`, not `site/dist`: the latter has an appcast, feature map, and other files not meant for this public Caddy route. Make a new release directory under `/opt/presentations/releases/` by copying the active site directory first, then overlay `dist-apparent/`. This retains any existing release/update or demo assets absent from the new package. Do not alter `/appcast.xml` or `/releases/` routes as part of a homepage deploy.

The Caddy `@publicApparent` path allowlist must include `/pond/*` for the frog images and `/team/*` for the team portraits and logos; it must not expose private prototype paths, the feature map, or the entire release directory. Validate any Caddyfile change with `caddy validate`, reload Caddy, and check that the old page is still served. Switch the `apparent-site` symlink atomically to the staged release; keep the old target for rollback. Compare public HTML and required image hashes with the packaged files and test desktop/mobile interactions in a browser. Cloudflare can cache a **pre-deploy 404** on a new image path for four hours; use a new query string or purge the specific cached URL before calling it healthy. The lily uses `?v=1` for this reason.

Rollback: atomically point `apparent-site` at the previous release target; restore the backed-up Caddyfile and reload only if the allowlist change itself caused trouble. Verify the old homepage and any affected update paths after rollback.
